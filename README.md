# 梦幻灵宠 · Pet Saga

一个正在迭代的宠物收集与回合制战斗游戏原型，使用 HTML、CSS 和原生 JavaScript 编写，适配手机浏览器。

## 本地运行

下载仓库后，用浏览器打开 `index.html` 即可游玩，无需安装依赖或构建。

游戏存档保存在当前浏览器的 `localStorage` 中。切换浏览器、设备或网址后，存档可能不同。重置存档需要二次确认。

## 当前玩法

- 宠物捕捉、宝宝与变异品质、进化、资质范围提示。
- 宠物详情支持免费改名和恢复种族名，1–12个字符；进化、洗炼和刷新保留自定义名字，炼化新宠使用种族名。
- 队伍加点预览与确认、炼化与技能继承。所有父母技能（包括任意五行弱点）均可继承，独有技能50%、共有技能80%；炼化可突破基础技能格上限，有机会保留全部不同技能，新增技能格随宠物存档保存。
- 炼化后停留原页，显示资质、成长率和技能结果评价；支持记住快速炼化选项及回看上次结果。
- 首页三个固定上阵栏位，可拖动上阵、替换、换位和下阵；手机支持拖动把手或点选放入。
- 可全部下阵并保存空阵容，手动与自动开战前检查至少有一只可参战宠物。
- 主线连续自动战斗，失败后退回上一关挂机。
- 单体与群体法术、魔法值、治疗、控制、护佑和 Boss 行动预告。
- 嘲讽消耗8魔法，施放后至下回合结束吸引所有敌人的单体攻击（包括首领），群攻不受影响；可搭配反震返还25%实际物理伤害。大海龟、巨蛙的宝宝／变异天生携带嘲讽；旧宠可通过战斗掉落的低级技能书学习。自动战斗在气血至少50%、有队友且无人嘲讽时使用，避免重复施放。
- 格子背包，点击物品查看详情与使用；金币商店和钻石商店分别购买道具。
- 背包按补给、养成、材料、技能书、礼包分类；小礼包可单个或最多5个一起打开。
- 补给包和成长包提供固定道具，商店购买或战斗掉落；随机低级技能书包仅 Boss 掉落。
- 成长小礼包提供经验丹×3。已取消寿命系统与长寿丹；旧存档剩余长寿丹按每颗20钻石一次性退还。
- 钻石商店可解锁“整成绿的”皮肤，全宠通用，可免费换装和恢复原色，仅改变外观。
- 战斗页使用红蓝药，可在战斗前和战斗中调整自动用药阈值。
- 红药固定恢复100点气血，蓝药固定恢复30点魔法；宠物治疗消耗10魔法，恢复目标最大气血的30%。自动救急比较实际回复量，治疗不低于红药时优先治疗。
- 经验丹提供1小时全队战斗经验+100%，重复使用延长时长，离线期间继续计时；页面顶部显示倒计时。
- 性格药和特性胶囊的商品卡片内可选择使用对象。
- 怪物掉落红药／蓝药碎片，在背包材料中用5个同类碎片合成1瓶药，支持全部合成。
- 战斗道具与低级／高级技能书掉落、按参战数量分配经验；高级书仅 Boss 掉落。
- 独立宠物培养页：选择宠物、查看技能与空余技能栏、使用低级／高级技能书。
- 金柳露225金币，洗炼野生／宝宝（野生变为宝宝）；高级金柳露15钻石，专洗变异并保留变异身份。培养页二次确认后重随资质、成长及技能，显示前后对比；保留等级、经验、加点、五行、性格、特性、皮肤及进化形态。
- 金币商店价格：红药15／瓶（3瓶45）、蓝药25／瓶（3瓶75）、经验丹150、金柳露225、补给小礼包75、性格药300、进化石900。
- 无尽塔、每日悬赏、探险车队与离线收益。
- 模拟广告加速 2 小时收益。

广告和内购按钮目前是原型演示功能，尚未接入真实广告或支付服务。

## 开发

`index.html` 包含页面、样式和游戏逻辑，是本仓库的游戏源文件。

修改后在浏览器中刷新即可查看。提交代码时可使用：

```sh
git add index.html
git commit -m "Describe the game changes"
git push
```

这个仓库用于保存代码与版本。目前的游戏是网页原型；发布到 iOS App Store 还需要单独的应用打包与发布流程。
